# ACES REALTY

A premium, responsive landing experience for ACES REALTY — Dubai real estate advisory.

## Run locally

This is a lightweight static site with no build step. Open `index.html` directly, or serve it with any static server:

```bash
npx serve .
```

The experience uses CSS-based architectural visuals and restrained motion so it remains fast and graceful on mobile, with progressive enhancement for pointer and scroll interactions.
